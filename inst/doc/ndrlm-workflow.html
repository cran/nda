1 What ndrlm() adds

ndrlm() combines network-based dimensionality reduction with one supervised model per dependent variable. It can reduce the input side, the output side, both sides, or neither; retain excluded indicators as direct connections; fit OLS, ridge, elastic-net, or LOESS models; and tune NDA weights and thresholds with NSGA-II.

1. ReduceObserved indicators form input and/or output latent variables.
2. RegressLatent and direct variables enter the selected regression engine.
3. EvaluateMetrics, predictions, residuals, paths, and optimization history are retained.

NDRLM is predictive and exploratory. A fitted path is not, by itself, evidence of a causal effect. Its role as a data-driven benchmark for structural models is developed in Kosztyán (2026a).

2 Published latent-input example

The example follows the article’s low-sample-size mtcars analysis. The ten input indicators form two communities. The first groups cyl, hp, qsec, vs, and carb; the second groups disp, drat, wt, am, and gear. The two resulting input latent variables predict mpg.

X_car <- mtcars[, setdiff(names(mtcars), "mpg")]
Y_car <- mtcars["mpg"]
input_membership <- c(
  cyl = 1, disp = 2, hp = 1, drat = 2, wt = 2,
  qsec = 1, vs = 1, am = 2, gear = 2, carb = 1
)

fit_latent <- ndrlm(
  Y_car, X_car,
  latents = "in",
  optimize = FALSE,
  membership.X = input_membership,
  regression = "lm",
  seed = 42
)

4 Input, output, and full latent models

latents Predictors used by regression Responses used by regression
"none" observed X observed Y
"in" input NDA scores observed Y
"out" observed X output NDA scores
"both" input NDA scores output NDA scores

The next executable example reduces both sides. Two observed response indicators form one output latent variable. With dircon = TRUE, membership zero would retain an excluded indicator as a direct observed variable.

X_both <- mtcars[, c("cyl", "disp", "hp", "wt", "qsec", "vs", "am", "gear")]
Y_both <- mtcars[, c("mpg", "drat")]

fit_both <- ndrlm(
  Y_both, X_both,
  latents = "both",
  optimize = FALSE,
  membership.X = c(1, 2, 1, 2, 1, 1, 2, 2),
  membership.Y = c(1, 1),
  regression = "lm",
  seed = 42

5 Regression engines with visible results

The enclosing NDRLM interface is the same for every engine. OLS provides coefficient tests and intervals. Ridge stabilizes correlated predictors. Elastic net combines shrinkage with coefficient selection. LOESS provides a small-predictor nonlinear model but no linear-path significance tests.

fit_ols <- fit_latent

if (requireNamespace("glmnet", quietly = TRUE)) {
  fit_ridge <- ndrlm(
    Y_car, X_car,
    latents = "in", optimize = FALSE,
    membership.X = input_membership,
    regression = "ridge", lambda = 0.05,
    seed = 42
  )
  fit_elastic <- ndrlm(
    Y_car, X_car,
    latents = "in", optimize = FALSE,
    membership.X = input_membership,
    regression = "elastic_net", alpha = 0.5, lambda = 0.05,
    seed = 42
  )
  engine_results <- rbind(
    OLS = fit_ols$fit_stats,
    Ridge = fit_ridge$fit_stats,
    Elastic_net = fit_elastic$fit_stats
  )
  engine_results
  round(cbind(
    ridge = fit_ridge$fits[[1]]$standardized_coefficients,
    elastic_net = fit_elastic$fits[[1]]$standardized_coefficients
  ), 3)
} else {
  cat("Install the suggested package 'glmnet' to run ridge and elastic net.\n")
}

The displayed ridge and elastic-net values are standardized coefficients. The path plots use the same scale by default, making linear path magnitudes comparable across differently scaled predictors and responses. Prediction metrics should still be compared on a common validation design when prediction is the scientific goal.

6 NSGA-II optimization and convergence history

When optimize = TRUE, NSGA-II tunes indicator weights and the four NDA thresholds. This deliberately small run demonstrates the complete interface. Larger populations, more generations, and repeated runs are appropriate for a final analysis.

fit_optimized <- ndrlm(
  Y_car, X_car,
  latents = "in",
  membership.X = input_membership,
  optimize = TRUE,
  target = "adj.r.square",
  rel_weight = TRUE,
  lower.bounds.x = rep(0.5, ncol(X_car)),
  upper.bounds.x = rep(1.5, ncol(X_car)),
  lower.bounds.latentx = c(0, 0, 0, 0),
  upper.bounds.latentx = c(0.01, 0.01, 0.01, 0.01),
  popsize = 4,
  generations = 3,
  restarts = 1,
  regression = "lm",
  seed = 42
)

7 Static and interactive latent path networks

7.1 Static latent path network

The both-sides model is used here because it shows the full four-layer structure: observed inputs, two input latent variables, one output latent variable, and observed outputs.

path_network <- plot(
  fit_both,
  sig = 1,
  interactive = FALSE,
  show_edge_labels = TRUE,
  shape = "automatic"
)
path_network

Both-sides NDRLM graph. Rectangles are observed indicators, circles are latent variables, and path colour carries sign.

Observed variables are rectangles and latent variables are circles, following standard structural-model notation. Each latent variable and its observed indicators share one colour from the default light qualitative palette. Measurement loadings are grey. Positive regression paths are green, negative paths are red, and absolute magnitude is mapped to width separately within loadings and structural paths. Structural labels and widths use standardized coefficients for OLS, ridge, and elastic net; loading labels retain their loading scale. Measurement links between observed and latent variables are dashed; structural paths are solid. Latent nodes are centred on the indicators assigned to them. Active layers are packed without leaving blank columns, and the default fills are slightly lightened and translucent. Edge labels use opaque backgrounds displaced from their paths. Colours, line types, shapes, and the minimum/maximum width can be overridden explicitly when a publication requires another convention.

7.2 Interactive latent path network

The interactive graph preserves the static layout and visual grammar. Nodes remain movable, and edge labels stay readable on an opaque background while the view is zoomed or rearranged.

interactive_path_network <- plot(
  fit_both,
  sig = 1,
  interactive = TRUE,
  show_edge_labels = TRUE,
  shape = "automatic"
)
