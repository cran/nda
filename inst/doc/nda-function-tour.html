1 Purpose and workflow

The nda package prepares structured data, measures full and conditional associations, selects indicators, constructs network-based latent variables, and links those latent variables to supervised response models. The methods follow the original and generalized NDA frameworks (Kosztyán et al. 2022, 2024) and their supervised extension (Kosztyán 2026a).

Every visible code block below is executable and is followed by the result it is intended to produce. The examples remain deliberately small so that the vignette can be built as part of a routine package check.

1. Preparedata_gen() and normalize()
2. AssociatedCov(), dCor(), pdCor(), spdCor()
3. Selectfs.KMO() and fs.dimred()
4. Modelndr() and ndrlm()

2 Function map

Task Functions and methods Main result
Data preparation data_gen(), normalize() dense or sparse data with controlled scaling
Association dCov(), dCor(), pdCor(), spdCor() full, partial, or semipartial dependence matrix
Feature selection fs.KMO(), fs.dimred() retained indicators and named exclusions
Unsupervised reduction ndr() plus print(), summary(), predict(), plot(), biplot() communities, latent scores, loadings, and graphs
Supervised modelling ndrlm() plus print(), summary(), predict(), fitted(), residuals(), plot() latent-variable regression and path networks

3 Structured data generation

5 Full and conditional distance association

dCov() and dCor() measure unconditional dependence. pdCor() removes the other variables from both sides; spdCor() removes them from one side and can therefore be asymmetric.

association_data <- mtcars[, c("mpg", "disp", "hp", "wt")]

dcov_matrix <- dCov(association_data)
dcor_matrix <- dCor(association_data)
pdcor_matrix <- pdCor(association_data)
spdcor_matrix <- spdCor(association_data)

The bubble maps use a common scale, so differences in symbol size are directly comparable. Square area represents absolute association and colour carries the sign. This makes the reduction from full to conditional association more visible than a smooth raster image.

association_bubbles <- function(z, main) {
  z <- as.matrix(z)
  nr <- nrow(z); nc <- ncol(z)
  plot(c(0.5, nc + 0.5), c(0.5, nr + 0.5), type = "n",
       axes = FALSE, xlab = "", ylab = "", main = main, asp = 1)
  grid <- expand.grid(x = seq_len(nc), y = seq_len(nr))
  values <- as.vector(t(z[nr:1, , drop = FALSE]))
  symbols(grid$x, grid$y,
          squares = 0.65 * sqrt(pmin(1, abs(values))), inches = FALSE,
          bg = ifelse(values < 0, "#C62828", "#009E73"),
          fg = "white", add = TRUE)
  axis(1, at = seq_len(nc), labels = colnames(z), las = 2)
  axis(2, at = seq_len(nr), labels = rev(rownames(z)), las = 1)
  text(grid$x, grid$y, labels = formatC(values, digits = 2, format = "f"),
       cex = 0.65, col = "black")
  box()
}

op <- par(mfrow = c(1, 3), mar = c(6, 5, 3, 1))
association_bubbles(dcor_matrix, "Full dCor")
association_bubbles(pdcor_matrix, "Partial dCor")
association_bubbles(spdcor_matrix, "Semipartial dCor")

7.2 NDRLM: a latent input model from the published example

The supervised example follows the low-sample-size mtcars analysis in Kosztyán (2026a). Ten observed input indicators form two input-side latent variables, which are then used to model fuel efficiency.

X_car <- mtcars[, setdiff(names(mtcars), "mpg")]
Y_car <- mtcars["mpg"]
input_membership <- c(
  cyl = 1, disp = 2, hp = 1, drat = 2, wt = 2,
  qsec = 1, vs = 1, am = 2, gear = 2, carb = 1
)

ndrlm_fit <- ndrlm(
  Y_car, X_car,
  latents = "in",
  optimize = FALSE,
  membership.X = input_membership,
  regression = "lm",
  seed = 42
)
summary(ndrlm_fit)

8 Visible model results

All figures are static and portable. In an NDR graph every observed indicator uses a rectangle; community membership is encoded by colour only. Positive associations are green, negative associations are red, and absolute magnitude controls edge width. In an NDRLM graph rectangles denote observed variables and circles are reserved for latent variables. The NDR network below contains observed indicators only, drawn as rectangles. Its communities are groups of indicators, not additional nodes named C1 or C2. In the biplot, NDA1 and NDA2 are score axes. In the supervised network, NDAin1 and NDAin2 are two distinct latent predictor nodes. These are three views of two different fitted models; their community numbers are local to each model and do not identify shared variables across models.

nda_network <- plot(

8.3 Latent predictor path model

Each observed car indicator appears once as a rectangle; each of the two latent predictors appears once as a circle. Fuel efficiency (mpg) is an observed response. Edge labels show loadings or regression coefficients; these quantities have different units and should be interpreted separately.

ndrlm_network <- plot(
  ndrlm_fit, sig = 1, interactive = FALSE,
  show_edge_labels = TRUE, shape = "automatic"
)
ndrlm_network

Ten observed car indicators, two latent input predictors, and the observed mpg response.

For nda objects, predict() returns latent scores. For ndrlm objects, predict() returns response predictions, while fitted() and residuals() preserve response names. The dedicated workflow vignettes expand the two model families and execute their advanced options.
